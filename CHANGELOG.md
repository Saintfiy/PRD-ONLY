# Changelog

Semua perubahan penting pada proyek ini dicatat di sini.

## [0.2.0] - 2026-11-25
### Ditambahkan
- Layar Pencarian dan Saran dengan riwayat pencarian dalam memori.
- Filter kategori dan pengurutan hasil, serta promo terkait berdasarkan kategori produk.
- Kontrol pengaturan banner kampanye di menu Akun.
- Perubahan alamat dan pilihan pengiriman pada Checkout; ringkasan pembayaran menampilkan voucher dan asuransi sebelum tombol bayar.
- Aksi Beli Langsung, indikator pelacakan pesanan yang dapat diperbarui, dan detail pesanan contoh saat belum ada pesanan baru.
- Penyempurnaan tampilan mobile, navigasi aksesibel, dan area ketuk tombol minimal 44 px.

## [0.1.0] - 2026-11-24
### Ditambahkan
- PRD lengkap pada README.md (masalah, tujuan, pengguna, kebutuhan UX-01 sampai UX-07, struktur informasi, alur, spesifikasi layar).
- Prototype web statis di folder `web/` (HTML, CSS, JavaScript tanpa build) dengan data dummy.
- Layar: Beranda, Hasil Pencarian, Detail Produk, Keranjang, Pusat Promo, Checkout, Pembayaran, Konfirmasi, Detail Pesanan, Kategori, Akun.
- Voucher Terbaik otomatis di Keranjang dengan tombol Ganti ke Pusat Promo.
- Simulasi pembayaran gagal (metode Dompet digital) dengan opsi Coba lagi dan Ganti metode.
- Deployment otomatis ke GitHub Pages lewat GitHub Actions.
### Belum
- Riwayat dan saran pencarian, Pengaturan Tampilan Promo, dan usability test.
